Backup & Restore

cloud_done Automatic Cloud Backup Daily backups run automatically via GitHub Actions

Your Firestore data is automatically backed up every day at 6:00 AM IST. Backups are kept for 7 days and can be downloaded from the GitHub Actions page.

cloud_download Export Backup Download your entire database as a file

This downloads a copy of all your data (students, attendance, payments, settings). Keep this file safe — if your browser data is cleared, you can restore from it.

cloud_upload Restore from Backup Upload a previously exported backup file

warning This will replace ALL current data with the data from the backup file. This action cannot be undone.
